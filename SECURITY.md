# Security Policy

This repository hosts an open-source course: hands-on materials (notebooks,
scripts) and a static documentation site. It contains no hosted runtime services
and stores no user data.

## Reporting a vulnerability

If you discover a security issue (for example, a malicious link in course
metadata, a content-injection issue, or a supply-chain concern in a dependency),
please report it privately:

- Open a confidential issue in this project, or
- Contact the DLI Open Source Playbook maintainers (see `CODEOWNERS`).

Please do **not** disclose security issues publicly until they have been
reviewed and addressed.

## Scope

- Course materials, the docs-site build configuration, and the CI pipeline in
  this repository.
- Front-end dependencies and the shared theme used to build the docs site.
